## 📖 Sobre

Este repositório reúne todas as atividades, projetos, trabalhos, exercícios e avaliações desenvolvidos durante minha graduação em **Tecnologia em Informática para Negócios** na **FATEC São Bernardo do Campo**.

O curso possui duração de **6 semestres**, contemplando disciplinas voltadas para:

- Desenvolvimento de Software
- Banco de Dados
- Engenharia de Software
- Gestão de Projetos
- Infraestrutura
- Segurança da Informação
- Redes
- Qualidade de Software
- Gestão Empresarial

A matriz curricular utilizada neste repositório segue o Projeto Pedagógico do Curso de Tecnologia em Informática para Negócios da Fatec São Bernardo do Campo. :contentReference[oaicite:1]{index=1}
