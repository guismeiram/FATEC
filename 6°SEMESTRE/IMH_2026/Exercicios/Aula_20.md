# Projeto Full Stack — .NET + React

## 📌 Descrição
Sistema de gestão de produtos com autenticação JWT,
dashboard e deploy via Docker.

## 🛠️ Stack
- ASP.NET Core 8
- React + Vite
- JWT
- Docker / Docker Compose

## 🧱 Arquitetura
- Clean Architecture
- DTOs
- Services
- Repositories

## 🚀 Execução
docker compose up --build

## 🔐 Segurança
- Autenticação JWT
- Rotas protegidas
- CORS configurado

## 📈 Próximos Passos
